# references/

Long supporting docs that don't need to be in Claude's main context on every
invocation. The skill's `SKILL.md` links here by relative path when a deeper
reference is needed.

Examples of content that belongs here:

- Full Common Model field schemas
- Per-language SDK quickstarts (install + initialization)
- Webhook event type tables
- Auth flow diagrams and edge cases

Keep `SKILL.md` focused on the user's primary path. Put exhaustive detail here.
